# 16. Frequently Asked Questions (FAQ)

**Where can I find the completed BA documents?**
In the `workflow/05_ba_docs/` folder.

**How do I view formatted documents?**
Double-click the `.md` file, then press `Ctrl+Shift+V` (Windows) / `Cmd+Shift+V` (Mac).

**What is Q-XXX?**
Numbered questions generated by Claude about missing information from the client.

**Something broke, what should I do?**
Type `/session-loader` — it shows the current state and next step.

**Can I re-run `/ba` if something changed?**
Yes, any time. The system always starts from the current state.

**Why won't the system let me generate documents?**
Because a Q-XXX question is still unanswered — by design, audit-ready documentation can't have open issues.

**Can I delete from memory?**
Not automatically — memory files only grow. You can manually edit files in `.claude/memory/`.

**Can I use it for multiple projects?**
Yes — create a separate repository copy from the template for each project.
