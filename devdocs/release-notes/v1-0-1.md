## What Changed

### Refaktorálás

### Fájlkonverter: AI agent → Python csomag (`convert_all`)
A monolitikus `file-converter-agent.md` (308 sor AI agent) és a 6 önálló szkript
(`convert_docx.py`, `convert_eml.py`, `convert_msg.py`, `convert_pdf.py`, `convert_pptx.py`, `convert_xlsx.py`)
helyett egy moduláris Python csomag (`convert_all/`) veszi át a konverziót: `core.py`, `scanner.py`,
`registry.py`, `log.py`, `report.py`, 5 konverter osztály — kevesebb AI token, jobb hibakezelés.
*(plans/done/file-conversion-refactor.md)*

### Session-loader: shell szkriptek → Python
A `.claude/scripts/session-loader.ps1` és `session-loader.sh` helyett egységes
`session_loader.py` Python szkript; a `/session-loader` SKILL.md ennek megfelelően frissítve.
*(plans/done/workflow-review.md)*

### `/ba-workflow` skill eltávolítva
A `/ba-workflow` skill (`skills/ba-workflow/`) törlésre került — funkcionalitása a
`/ba` orchestrator-on belül él tovább.
*(plans/done/workflow-review.md)*

---

### Új funkciók

### AI-alapú képkonverzió
A `convert_all` pipeline képfájlokat (`.png`, `.jpg`, `.bmp`, `.webp`) is feldolgoz:
a `markitdown` LLM-támogatásával szöveges leírást generál a képekből, és beemeli a specifikációba.
*(plans/done/image-converter-plan.md)*

### Forrás-traceability SHA fingerprint-tel
Minden spec-builder által generált elem (`FR-XXX`, `Q-XXX`, stb.) inline `[Forrás: fájlnév · sha8]`
jelzést kap; a `fingerprint.py` szkript számítja a SHA-256-ot, a `SPEC_LOG.md` tárolja.
*(plans/done/full-documentation-traceability.md)*

### BA dokumentum sablonok
6 új referencia sablon (`references/ba-docs/`): BRD struktúra, glossary, RAID log, Step 4 riport,
traceability mátrix, user story — a `ba-document-agent` ezek alapján generál.
*(plans/done/workflow-review-2.md)*

### Mermaid diagram sablonok
8 új Mermaid diagram sablon a `/mermaid-diagrams` skillhez: flowchart, sequence, ER, state,
CI/CD pipeline, microservices, event-driven, git graph.

### `reset_project.py` és `test_convert.py`
Új fejlesztési segédeszközök: projekt visszaállítás teszteléshez, konverziós pipeline smoke test.

---

### Workflow struktúra

### Workflow almappa struktúra bevezetve
Az egységes `workflow/` helyett tagolt almappák: `01_project_info/`, `01_project_info/_system/`,
`02_answers/`, `03_ba_docs/` — a ba-orchestrator state machine ezek alapján navigál.

---

### Dokumentáció és szabályok

### Memory fájlok átnevezve nagybetűsre + schema referenciák
A `.claude/memory/` fájlok (`conversion_log.md` → `CONVERSION_LOG.md` stb.) egységesen
nagybetűs elnevezést kaptak; sémáik a `references/memory/` mappában lesznek dokumentálva.

### Új szabályok: traceability és page-folder
`traceability.md` — kötelező SHA fingerprint minden kimeneti elemhez;
`page-folder.md` — a GitHub Pages `page/` mappájának kezelési szabályai.
