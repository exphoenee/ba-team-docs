## What Changed

### Kezdeti kiadás — BA Tool alapfunkciók

### Agents (6 db)
A BA Tool magja: orchestrator, spec-builder, BA document generator, file converter, memory manager.

| Agent | Feladat |
|---|---|
| `ba-orchestrator` | Főkoordinátor — állapotgépet futtat, delegál, jelent |
| `spec-builder-agent` | Strukturált specifikáció generálás input fájlokból |
| `ba-document-agent` | Teljes BA dokumentumkészlet generálása (BRD, User Story, stb.) |
| `file-converter-agent` | AI-alapú fájlkonverzió (docx, xlsx, msg, eml, pdf, pptx) |
| `memory-agent` | `.claude/memory/` kizárólagos kezelője |

### Skills (8 db)
Felhasználói parancsok a BA Tool interakcióhoz.

| Skill | Funkció |
|---|---|
| `/ba` | Fő belépési pont — orchestrator indítás |
| `/ba-workflow` | Workflow kezelés (később eltávolítva) |
| `/business-analyst` | BA dokumentumok generálása |
| `/convert` | Fájlkonverzió indítása |
| `/memory-handler` | Memória műveletek |
| `/mermaid-diagrams` | Mermaid diagram sablonok |
| `/session-loader` | Munkamenet betöltés |
| `/spec-builder` | Specifikáció építés |

### Workflow struktúra
Tagolt mapparendszer a projektfájlok rendezéséhez:
`01_project_info/`, `02_answers/`, `03_ba_docs/` almappákkal.

### Szabályok
`language.md` — nyelvi előírások; `memory-access.md` — memória hozzáférési protokoll.

### Dokumentáció
- `HANDBOOK.md` (882 sor) — teljes felhasználói kézikönyv
- `improvements.md` — fejlesztési javaslatok és roadmap
- `development.md` — fejlesztői dokumentáció

### Statikus weboldal (`page/`)
GitHub Pages-en futó dokumentációs oldal: index.html + app.js + style.css,
audiós tartalmak (4 beszélgetés mp3/m4a), PDF prezentáció és felhasználói kézikönyv.

### Telepítés
`install.ps1` (Windows) és `install.sh` (Linux/macOS) telepítő szkriptek.
